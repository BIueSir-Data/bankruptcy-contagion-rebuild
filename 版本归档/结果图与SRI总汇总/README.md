## 一、从 V1.0 到 V2.1e 各版本渐进特性与口径演变（累积覆盖关系）

> 本次重建采用**渐进累积升级**设计：每个新版本均**完全覆盖前一版本的全部修正**，再叠加新的属性或口径改动（主设定统一为 `γ = 0.25, p0 = 0.5, φ = 0.5, R = 1`）。

| 版本 | 继承关系 | 本版新增属性 / 修改口径 | 对应《11.16 修订指导》条款 | 关键变化与现象 |
| :--- | :--- | :--- | :--- | :--- |
| **V1.0_D0** | 基线锚点（干净数据 + 旧引擎） | 1. 修复 29 个非金融行业被误做二次差分的问题，恢复真实单季营收/成本/利润（保留率 `67.5% → 99.79%`，找回 4 行业 `2021q4`）<br>2. 移出 `银行`/`非银金融` 单独保存（另保留 31 行业合并表）<br>3. 修复矩阵 `iloc[:-1, :-1]` 误删 577 格末位企业 Bug；缺失显式记 `NA`<br>4. 引擎仍沿用旧版 8.31 逻辑（净利润作存活值、`k=E/R`、`e^(-vis)`） | **D0.1–D0.6**（数据口径审计、金融分离、单季 19Q SRI） | 伪季节性高 SRI 消失；29 主样本 `SRI_ma4 = 0.0074`；若混入金融则银行 100% 破产把 31 行业 `SRI_ma4` 暴拉至 `0.0722` |
| **V1.0_D1** | 同 V1.0_D0 数据与旧引擎 | 新增 `propagation_enabled` 传播开/关成对对照（同 `B(0)`、同种子），拆出直接损失、传播新增损失与最大传染代数 `Max_Prop_Gen`，测试 `γ = 0.25 & 0.45` | **D1**（无传播基准对照） | `γ=0.25` 时 91.7% 实体窗无传染（`ΔBR=+0.0035`）；`γ=0.45` 时 97% 停在 1 代（最大 2 代） |
| **V2.0** | **覆盖 V1.0 干净数据** + 核心公式重写 | 1. **缓冲与阈值**：`C_i(0) = total_assets - total_liab`（所有者权益），`U_i = 0`（权益耗尽即激活）<br>2. **可视度项**：恢复 `α·e^(-γ_v·vis_b) + (1 - α)`（`α=0.5, γ_v=1.0`，介数中心性 `vis_b`）<br>3. **利润率 V1**：取非负 `max(τ, 0)` 并统计截断企业数<br>4. **`k_b` 取倒数与防除零**：公式 1a 中 `k_b = R/E (>1)`（VS 评分成本率 `E/R` 不变）；`ΔS` 直接相乘不除 `τ`；严格剔除 `rev≤0` 或 `cost≤0`<br>5. **指标口径**：损失率改 `Σ(C_i(0)-C_i(T))⁺ / ΣC_i(0)⁺`（分母 0 记 `NA`）；WCC 改 Fagiolo (2007) 有向加权定义；SRI 原值不做 Z 变换 | **第 1, 3, 4, 5, 12 条** | 银行不再虚假全灭；29 主样本 `Loss_Ratio = 0.1137`、`SRI_ma4 = 0.0249`；但有 `22,414` 条（24.9%）企业因 `τ<0` 被截断为 0，实体行业仅 `1/539` 窗发生二次破产 |
| **V2.1** | **完全覆盖 V2.0** + 动力学与同步更新 | 1. **边方向与 `Ego` 修复**：明确 `a→b` 为供应商→客户，修复旧代码 `1a/1b` 查反邻居方向的 Bug，统一改为全邻居破产占比<br>2. **二次影响几何衰减**：上步受冲击则以 `p_b = p0·ego_ratio` 再受 `φ·‖F‖`（期望严格等于 `φ‖F‖p_b/(1-p_b)`，10 万次单测误差 `<1%`）<br>3. **健康下传 V1 守恒**：随机选一健康下游，强制下传总量 `≤ ΔS`<br>4. **同步更新 + 双重早停**：第 `s` 步统一按 `s-1` 状态算力/扣减/激活；连 3 步无新增且残余冲击 `<10⁻⁶×总缓冲` 停止<br>5. **诊断与接口**：自动输出 `γ→θ_k→BR0` 表，预留外生冲击 `δ` | **第 2, 6, 7, 8, 9, 11 条** + 6/6 单元测试 + ODD 文档 | 动力学与同步更新完全合规（539/539 窗全部收敛）；实体行业 `Loss_Ratio = 0.1136`、`SRI_ma4 = 0.0249`（因实体窗基本未触发二次激活，与 V2.0 高度一致） |
| **V2.1b** | **完全覆盖 V2.1** + 利润率切 V2 | 将第 4 条利润率由 **V1 净利润率 `max(τ, 0)`** 切换为 **V2 毛利率 `max(1 - E/R, 0)`** | **第 4 条（V2 并列对照）** | 被截断为 0 的样本从 `22,414`（24.9%）大幅降至 `2,728`（3.0%）；`Loss_Ratio` 微升至 `0.1139` |
| **V2.1c** | **完全覆盖 V2.1b** + 切换稀疏网络 | 将仿真网络由**稠密全连接矩阵 (`full`)** 切换为 **`disparity_alpha = 0.05` 稀疏骨干网 (`sparse`)**，消除边权份额被稀释至 `~1/N` | **网络结构对照** | 29 主样本 `Loss_Ratio` 升至 `0.1150`（`SRI_ma4 = 0.0252`）；**非银金融激活显著二次传染（`dBR = +13.20%`）**，31 行业 `SRI_ma4` 升至 `0.0323` |
| **V2.1d** | **完全覆盖 V2.1c** + 健康下传切 V2 | 将第 7 条健康节点下传由 **V1（随机单下游）** 切换为 **V2（按边权分摊给全部健康下游，总量严格等于 `ΔS`）** | **第 7 条（V2 并列对照）** | 29 主样本 `Loss_Ratio = 0.1154`；非银金融 `dBR = +13.41%`，31 行业 `SRI_ma4 = 0.0327` |
| **V2.1e** | **完全覆盖 V2.1d** + 外生缓冲冲击 | 按第 11 条对全系统企业初始正净资产缓冲统一施加 **`δ = 50%` 宏观压力扣减** | **第 11 条（压力实验 `δ`）** | 29 主样本 `Loss_Ratio` 升至 `0.1176`（`SRI_ma4 = 0.0257`），但仍仅 `1/539` 实体窗触发二次破产；非银金融 `dBR` 进一步升至 **`+19.70%`**（31 行业 `SRI_ma4 = 0.0356`） |
| *(预备) V2.2* | **完全覆盖定稿 V2.1x** + 蒙特卡洛重复 | 每设定 `R = 50` 次独立种子重复（若 `SE(BRT) > 0.005` 自动扩至 `200` 次），输出均值与 5%–95% 区间（配置已就绪：`configs/v2_2_mc_convergence.yaml`，待老师拍板主设定后启动） | **第 10 条** | — |
