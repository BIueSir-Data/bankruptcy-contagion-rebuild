# V2.1 — 完全覆盖 V2.0 + 动力学与同步更新修复版

## 1. 本版说明（怎么跑出来的）
- **版本定位**：渐进冻结模型第二层（**V2.1**），**100% 覆盖 V2.0 的全部会计与社会力修正（第 1, 3, 4, 5, 12 条）**，并叠加《11.16 修订指导》第三节**第 2、6、7、8、9、11 条**动力学与工程严谨性修正（单组主设定 `γ = 0.25, R = 1`，已通过 `tests/test_engine_v2.py` 全部 6 项 2–3 节点手算及 10 万次二次影响单元测试）。
- **相对 V2.0 新增叠加的 6 项修正**：
  1. **第 2 条（边方向与 `Ego` 修复）**：明确 `a → b` 为供应商 → 客户，修复旧代码 `1a/1b` 查反邻居方向的 Bug，统一改为全邻居破产占比（`ego_mode: all_neighbors`）；
  2. **第 6 条（二次影响几何衰减）**：上一步受冲击则本步以概率 `p_b = p0 · ego_ratio` 再受 `φ · ‖F‖`（理论期望严格等于 `φ·‖F‖·p_b/(1-p_b)`，10 万次单测误差 `<1%`）；
  3. **第 7 条（健康节点下传守恒）**：主设定 V1 随机单下游，强制下传总量 `≤ ΔS`（已预留 V2 按边权分摊开关）；
  4. **第 8 条（同步更新）**：第 `s` 步统一基于 `s-1` 状态算力、统一扣减、统一判定激活；
  5. **第 9 条（双重停止规则）**：连续 3 步无新增激活且待执行二次影响 `< 10⁻⁶ × ΣC_i(0)⁺`（或 `S_max = 1000`），分别记录 `T_last_activation`、`T_loss_stop`、`T_run`；
  6. **第 11 条（`γ → θ_k → BR0` 诊断与外生冲击接口）**：自动输出 `gamma_theta_br0_diag.csv` 并预留外生缓冲扣减参数 `δ`（主设定 `δ = 0`）。
- **复现命令**：
  ```powershell
  python tests/test_engine_v2.py
  python src/run_v2.py --config configs/v2_1_dynamics_sync.yaml --workers 8
  ```

## 2. 核心结果摘要（29 主样本行业，539 有效窗 / 12 缺失窗，0 未收敛）
- **核心指标**：`BR0 = 0.2196`，`BRT = 0.2196`，`ΔBR = 0.0000`（`1/539` 窗发生传染），`Loss_Ratio = 0.1136`，`SRI_raw 均值 = 0.0254`，`SRI_ma4 均值 = 0.0249`。
- **与 V2.0 的对比说明**：由于在净资产缓冲 + `V1: max(τ, 0)` + 稠密矩阵 + `γ = 0.25, δ = 0` 下，538/539 个窗口本身未触发二次激活，因此 V2.1 的动力学与同步更新修正与 V2.0 结果高度一致（`Loss_Ratio` 仅差 `0.0001`）。
- **后续建议**：待汇报老师确认后，再通过切换 **V2 毛利率 `max(1 - E/R, 0)`**、**稀疏化网络 `sim_network: sparse`** 或 **外生冲击 `δ > 0`** 激活真实级联传染，之后再运行 **V2.2（`R = 50 / 200` 蒙特卡洛重复）**。
