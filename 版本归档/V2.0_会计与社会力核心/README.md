# V2.0 — 会计口径与社会力核心修复版

## 1. 本版说明（怎么跑出来的）
- **版本定位**：渐进冻结模型第一层（**V2.0**），在 **V1.0 干净单季数据** 基础上，按《11.16 修订指导》第三节实施**第 1、3、4、5、12 条**会计与社会力核心修正（暂保持旧版 `Ego`、二次影响与早停开关，留待 V2.1 叠加覆盖；单组主设定 `γ = 0.25, R = 1`，不做敏感性扫参）。
- **相对 V1.0 新增的 5 项修正**：
  1. **第 1 条（缓冲与阈值）**：`C_i(0) = total_assets - total_liab`（所有者权益），`U_i = 0`（权益耗尽即激活）；
  2. **第 3 条（可视度项）**：恢复论文形式 `α·e^(-γ_v·vis_b) + (1 - α)`，主设定 `α = 0.5, γ_v = 1.0`，`vis_b` 采用稀疏网络基准化介数中心性；
  3. **第 4 条（利润率非负）**：主设定 V1 取 `max(τ, 0)` 并统计被截断企业数；
  4. **第 5 条（`k_b` 取倒数与防除零）**：公式 1a 中 `k_b = revenue / operating_expense (> 1)`（VS 评分成本率 `E/R` 不变）；`ΔS` 直接相乘避免 `F/τ` 除零；严格剔除 `rev ≤ 0` 或 `cost ≤ 0`；
  5. **第 12 条（指标口径）**：损失率改 `Σ(C_i(0) - C_i(T))⁺ / ΣC_i(0)⁺`（分母为 0 记 NA）；WCC 按 Fagiolo (2007) 有向加权聚类系数计算；SRI 取原值不做 Z 变换。
- **复现命令**：
  ```powershell
  python tests/test_engine_v2.py
  python src/run_v2.py --config configs/v2_0_accounting_core.yaml --workers 8
  ```
- **对应配置文件**：`v2_0_accounting_core.yaml`（原运行目录：`runs/20261122_140531_V2_0_accounting_core`）。

## 2. 核心结果与机理诊断（29 主样本行业，539 有效窗 / 12 缺失窗，0 未收敛）
- **核心指标**：`BR0 = 0.2196`，`BRT = 0.2196`，`ΔBR = 0.0000`（仅 `1/539` 窗即 `公用事业` 出现 `+0.0052` 传染），`Loss_Ratio = 0.1137`，`SRI_raw 均值 = 0.0254`，`SRI_ma4 均值 = 0.0249`。
- **诊断统计**：`N_tau_clipped = 22,414`（24.9% 样本因 `τ < 0` 截断为 0 而免受冲击），`N_init_insolvent = 582`，`θ_k < 0` 窗口 `362 / 539`（67.2%）。
- **关键发现**：净资产存量缓冲远大于单季流量利润冲击，叠加稠密矩阵权重稀释与 24.9% `τ` 截断归零，导致 `γ = 0.25, δ = 0` 下几乎无二次传染；`11.37%` 的损失率几乎全部来自初始破产组的直接权益损失。
