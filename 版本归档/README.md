# 实验版本归档总览（V1.0 → V2.1e 渐进式重建）

本目录按**渐进累积版本号**归档全部全量实证产出（表格、配置副本、随机种子、日志及论文标准五图）。每次升级均**完全覆盖前一版本并叠加新修正**；原始带时间戳的运行目录仍保留在 `../runs/` 下以备溯源。
