# V1.0 — D1 无传播基准对照（γ = 0.25 & 0.45）

## 1. 本版说明（怎么跑出来的）
- **版本定位**：第一批先行检验 **D1（无传播基准对照）**，基于 V1.0 干净单季数据（`data/clean/`）与旧版 8.31/11.16 引擎（`src/engine_legacy_d1.py`）。
- **实验设计**：在 `γ = 0.25` 与 `γ = 0.45` 两个阈值下，对每个（行业，季度）窗口共享**完全相同的初始破产集合 `B(0)` 与随机种子**，分别运行“传播关闭（`off`）”与“传播开启（`on`）”，剥离直接初始损失与二次传播新增损失，并追踪最大传染代数 `Max_Prop_Gen`。
- **复现命令**：
  ```powershell
  python src/run_d1.py --workers 8
  ```
- **对应配置文件**：`d1_config.yaml`（原运行目录：`runs/20261121_222105_D1_no_propagation_benchmark`）。

## 2. 核心结果摘要（29 主样本行业，539 有效窗 / 12 缺失窗）
- **`γ = 0.25`**：
  - `BR0 = 0.2187` → `BRT_on = 0.2223`，净传染增量 `ΔBR = +0.0035`；
  - **91.7% 的窗口完全无二次传染**（`ΔBR > 0` 仅占 8.3%，`Gen ≥ 2` 仅占 0.2%，最大代数 2）；
  - `Prop_Added_Loss_Ratio = 0.0271`。
- **`γ = 0.45`**：
  - `BR0 = 0.5065` → `BRT_on = 0.5946`，净传染增量 `ΔBR = +0.0881`；
  - 77.7% 窗口触发传染，但 **97.0% 停在第 1 代**（`Gen ≥ 2` 仅 3.0%，最大代数 2）；
  - `Prop_Added_Loss_Ratio = 0.1583`；传染增量前 5 行业：`家用电器 (0.274)`、`综合 (0.207)`、`汽车 (0.205)`、`建筑材料 (0.199)`、`交通运输 (0.173)`。
